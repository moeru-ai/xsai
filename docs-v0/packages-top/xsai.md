# Use the xsai package {#xsai}

Import the core v0 utilities from one package.

This page describes the v0 API from `v0.5.1`.
Use v0 package builds with these examples.

```sh
npm i xsai@0.5.1
```

## Usage

Replace the individual `@xsai/*` import with `xsai`.

```ts
import { generateText } from 'xsai'
```

## Result

The imports use xsai instead of the individual @xsai packages.
